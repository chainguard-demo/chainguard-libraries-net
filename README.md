# chainguard-libraries-net

Demo projects and resources for Chainguard Libraries for .NET.

| Project | Description |
| --- | --- |
| [Banking Demo](dotnet-bank/README.md) | An ASP.NET Core 10 banking demo application with a minimal API and a single-page web UI. It uses NuGet packages from Chainguard Libraries for .NET. |
| [tools](tools/README.md) | Configuration and `chainctl` command examples for consuming Chainguard Libraries for .NET, with commands to confirm access from a workstation or CI job. |

Configure access to Chainguard Libraries for .NET, directly or through a
repository manager, using the commands and configuration in
[`tools`](tools/README.md). Then follow the demo's README to run it.
